# M12 人工审核与审批中心设计

## 功能描述

为 WallModel、Revit 写入、图纸审查、采购和知识待补提供统一的人工审核入口，将不可逆动作置于持久化审批之后。

## 功能实现流程

1. 查询当前用户有权处理的 `waiting_human` 任务。
2. 展示任务摘要、风险、输入版本、证据、差异和下一步动作。
3. 审批人选择批准、驳回或要求补件并填写意见。
4. 事务内写入 Approval、任务状态和 TaskEvent。
5. 批准投递恢复事件；驳回取消或转修订任务。

## 业务规则

- 审批动作由服务端 `next_action` 推导，客户端不能跳步骤。
- 审批必须校验角色、项目权限和输入版本，防止过期审批。
- Revit 写入必须有单独第二次审批。
- 审批人、时间、意见和前后哈希不可修改。
- 失败任务不能通过审批伪装成功。

## 使用角色

`reviewer`、`admin`；`project` 仅按项目策略批准 WallModel；普通用户不能审批。

## 界面设计要求

- 待办列表按风险和等待时间排序，支持项目/工作流筛选。
- 详情页先显示可读摘要，再显示 JSON、证据、差异和原图定位。
- 危险按钮使用二次确认和原因输入；批准按钮明确具体动作。
- 审批完成后显示下一阶段，而不是只弹 Toast。

## API 与数据

- `GET /api/v2/tasks/{id}`、`POST /tasks/{id}/resume`、`POST /reviews/{id}/decision`、`POST /builds/{id}/approve`。
- 表：`approvals`、`workflow_runs`、`task_events`。

## 异常与验收

- 无权限、版本冲突、任务已终态和非法动作均拒绝。
- 审批后任务能恢复/取消，事件序号连续，审计可回放。
