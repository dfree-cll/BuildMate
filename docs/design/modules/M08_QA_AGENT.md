# M08 问答入口与意图路由设计

## 功能描述

当前记忆实现：同一账号/项目/会话的最近历史、较早摘要与偏好参与问答；前端刷新后可恢复。简短追问结合用户历史补充检索上下文，历史回复不能替代当前 RAG 证据。详见 [Agent 记忆说明](../../AGENT_MEMORY.md)。

提供独立的自然语言问答入口。普通知识问题直接返回有证据的答案；合同审核、标书查询、建筑规范查询和采购/供应商请求由意图识别层调用对应的受控 Workflow。BIM 保留独立页面入口，问答中的 BIM 请求只负责跳转并预填任务。

## 功能实现流程

1. 用户创建会话并选择项目/专业/资料范围。
2. API 构造 RequestContext，校验会话和项目权限。
3. 意图识别器输出注册意图、参数、置信度和路由；低置信度只澄清。
4. `building_standard_query`、`bid_query` 和 `general_question` 调用 RAG；实时价格、模型和几何问题调用结构化工具。
5. `contract_review` 创建持久化任务，并并行调用合同条款结构化抽取、RAG（制度/规范/模板/历史条款）和确定性规则。
6. `procurement_query` 创建持久化任务，并并行调用 RAG（制度/合同/供应商资质）、结构化价格/预算/库存数据和确定性规则。
7. RAG 进行权限过滤、Dense/BM25 召回和可选重排；只有本次真实命中片段才能进入回答或 Finding。
8. 校验结构化答案和引用，返回答案、引用、检索运行 ID 或任务 ID；低置信度拒答或写入知识待补。

## 业务规则

- LLM 不能编造条文、页码、价格和模型状态。
- 意图识别不能生成未注册的 Workflow、工具名或执行代码。
- BIM 请求不绕过 BIM 页面、静态门禁、Dry-run 和人工审批。
- 引用必须存在于本次 `KnowledgeHit`。
- 高/中/低置信度分别对应回答、带不确定性回答、澄清/拒答。
- 会话消息和检索记录按项目权限保存。
- 连续两次非法结构化输出后任务失败。

## 使用角色

`admin`、`reviewer`、`project` 和被授权 `user` 可问答；管理员可查看审计和成本；审核员处理知识待补。

## 界面设计要求

- 左侧显示会话和项目范围，右侧显示回答或已创建的任务卡。
- 识别到合同审核、标书查询等业务意图时，先显示将执行的能力、输入文件和是否需要审核；用户确认后再创建任务。
- 识别到 BIM 请求时提供“打开 BIM 并预填”按钮，不把复杂建模配置塞进聊天气泡。
- 回答下方展示引用卡：文档、版本、页码、片段和打开原文。
- 低置信度使用警告标签并给出“补充资料/提交待补”按钮。
- 流式响应显示阶段，不显示内部 Prompt。

## API 与数据

- `POST /api/v2/chat/sessions`、`POST /chat/sessions/{id}/messages`、`GET /chat/sessions/{id}/events`。
- `POST /api/v2/chat/intents/preview`：在创建任务前预览意图和受控路由。
- 调用 `knowledge.search`、`bid.search`、`contract.extract`、`contract.review`、`material_prices`、`budget.check`、`model_diff` 等受控工具。
- 意图路由记录保存原始意图、路由、置信度、缺失参数和操作者确认。
- 表：会话消息、`retrieval_runs`、`retrieval_hits`、`llm_calls`。

## 异常与验收

- 无命中、知识库不可用、LLM 超时和引用校验失败均明确显示。
- 跨项目/租户资料不会出现在答案或引用中。
- 黄金问题集达到约定 Recall、引用覆盖率和答案有据率。
