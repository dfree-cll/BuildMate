# M15 管理员控制台设计

## 功能描述

为管理员提供租户、用户、项目、任务、知识库、审计、配置和系统健康管理。

## 功能实现流程

1. 管理员登录并进入租户管理范围。
2. 查询成员、项目、任务、文档和指标。
3. 对用户/项目/策略进行变更并记录审计。
4. 查看任务时间线、失败、重试、取消和死信。
5. 管理知识文档版本、索引任务和检索评估。
6. 执行非生产重置或运维动作，要求二次确认。

## 业务规则

- 仅 `admin` 可访问控制台。
- 生产数据删除、重置和策略变更需明确范围、原因和审计记录。
- 管理员也不能绕过 Revit 审批和几何门禁。
- 任务重试不得改变原始输入 Artifact。

## 使用角色

`admin`；审核员仅使用审核中心，不进入管理配置。

## 界面设计要求

- 左侧按用户/项目、任务、知识、审计、系统分组。
- 高风险操作显示影响范围、当前版本和二次确认。
- 任务列表支持状态、项目、工作流、失败码和时间筛选。

## API 与数据

- 管理员专用当前 API、任务/知识/审计查询 API。
- 使用 `users`、`memberships`、`projects`、`workflow_runs`、`audit_events` 等表。

## 异常与验收

- 非管理员访问返回 403。
- 管理操作有审计事件；重启后任务、文档和配置可恢复。
