# M14 前端应用壳与项目工作台设计

## 功能描述

提供 Vue 应用框架、登录态、租户/项目上下文、角色导航、统一反馈、领域状态和长任务恢复能力。当前产品保留 BIM 和问答两个清晰入口：BIM 使用显式流程，问答使用自然语言和意图路由。

## 功能实现流程

1. 启动应用，检查 Token 和当前用户。
2. 加载租户、项目和项目级权限。
3. 渲染角色可见导航和仪表盘（BIM、问答、审核端；管理能力按角色显示）。
4. 页面通过 API Client 调用当前 API，不直接访问数据库。
5. 任务页面订阅 SSE；断线时使用游标轮询。
6. 路由切换/刷新后从 URL 或 Pinia 恢复任务和项目上下文。

## 业务规则

- 前端角色隐藏不能代替后端权限。
- 所有业务页面必须有项目上下文。
- 领域状态按 `auth/project/artifact/task/review/modeling/chat/knowledge` 拆分。
- BIM 与问答是两个独立导航入口；问答识别到合同审核/正式标书审查时显示任务确认卡，不直接替换为复杂表单。
- API 错误统一转换为用户可读文案并保留 Trace ID。

## 使用角色

全部登录用户；菜单和数据按角色、租户、项目过滤。

## 界面设计要求

- 统一顶部上下文栏、侧边导航、面包屑、卡片、表格和状态标签。
- 页面必须覆盖 loading、空、无权、失败、待审批、成功状态。
- 复杂 JSON 默认折叠，摘要优先。
- 遵守 [UI_UX_DESIGN.md](../../UI_UX_DESIGN.md)。

## API 与数据

- Axios/Fetch Client、SSE Client、Pinia Stores、Vue Router。
- 不持久化敏感 Token 到业务日志；本地会话策略按安全要求配置。

## 异常与验收

- Token 过期自动刷新或跳登录；SSE 断线不丢任务。
- 页面刷新后可回到原任务；构建和类型检查通过。
