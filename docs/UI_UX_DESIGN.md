# BuildMate UI / UE 界面风格设计约束与规格

**版本**：当前设计
**适用范围**：所有前端页面、弹窗、任务状态、报告和审核界面
**关联总设计**：[DESIGN.md](DESIGN.md)

## 1. 设计目标

BuildMate 是工程业务系统，不是纯聊天产品。界面必须优先表达项目上下文、事实证据、任务状态、风险和下一步操作，让用户不读原始 JSON 也能作出判断；同时保留 JSON/证据展开入口供专业人员复核。

核心体验原则：

1. **清晰**：页面先展示结论、状态、数量和下一步。
2. **可信**：所有 AI 结果显示来源、版本、页码/实体定位和置信度。
3. **可控**：不可逆操作使用显著的人工确认和风险提示。
4. **可恢复**：任务刷新、断线、失败和重试状态不丢失。
5. **一致**：相同状态、按钮、颜色、表格和错误在全站统一。
6. **克制**：采用简约科技风，以清晰留白、冷色强调、轻量玻璃层次和微动效表达品质。装饰不覆盖工程数据，不使用粒子背景、持续动画或不可读的纯 JSON 页面。

## 2. 技术与布局约束

- Vue 3 + TypeScript + Vite。
- 采用 Bootstrap 兼容的 12 列栅格、8px 间距基线；组件可以使用 Element Plus，但不得破坏统一设计令牌。
- 桌面优先（工程数据表和 BIM 叠图需要宽屏），最低支持 1280×720；平板采用单列折叠；手机只保证查看和审批，不保证复杂建模配置。
- 页面结构统一为：顶部上下文栏 → 左侧导航 → 主内容区 → 必要时右侧详情抽屉。
- 主内容最大宽度 1440px；表格、叠图和 JSON 查看器允许横向滚动，不压缩关键字段。

## 3. 视觉令牌

### 3.1 颜色

| 语义 | 色值 | 用途 |
|---|---|---|
| 主色 | `#0071E3` | 主按钮、链接、当前导航 |
| 成功 | `#16A34A` | 通过、交付完成、健康 |
| 警告 | `#D97706` | 待审批、不确定性、降级 |
| 危险 | `#DC2626` | 失败、拒绝、碰撞、门禁失败 |
| 信息 | `#0891B2` | 处理中、证据、提示 |
| 背景 | `#F5F5F7` | 页面背景 |
| 面板 | `rgba(255,255,255,.86)` | 卡片、表格、抽屉 |
| 正文 | `#1D1D1F` | 正文文字 |
| 次要文字 | `#6E6E73` | 辅助说明 |

不能只用颜色传达状态，必须同时显示文字、图标或状态标签。

### 3.2 字体与间距

- 中文优先：`-apple-system`, `SF Pro Display`, `Segoe UI`, `Microsoft YaHei`, sans-serif。
- 正文 14px，辅助 12px，页面标题 24px，模块标题 18px。
- 行高 1.5～1.7；表格行高不低于 40px。
- 间距使用 4/8/12/16/24/32px，避免任意值。
- 等宽字体只用于任务 ID、哈希、坐标、JSON 和日志。

## 4. 页面和导航规格

### 4.1 全局栏

- 左侧：BuildMate 标识和当前产品名称。
- 中间：租户选择器、项目选择器、楼层/上下文标签。
- 右侧：任务提醒、当前用户、角色、退出。
- 项目上下文缺失时，业务页面顶部固定显示警告，禁止静默使用默认项目。

### 4.2 导航可见性

- `admin`：全部入口、任务时间线、知识库、系统管理。
- `reviewer`：审核中心、BIM 审批、知识待补和被授权业务。
- `project`：项目、Artifact、BIM、问答、历史和被授权查询/任务。
- `user`：被授权项目、问答和只读结果。
- 前端隐藏只是体验优化，后端权限仍必须校验。

当前 固定保留两个普通用户入口：

1. **BIM**：显式选择图纸、楼层、坐标和 Revit 工作模型，按步骤完成识别、审核和交付。
2. **智能工作台（QA）**：自然语言查询规范、标书和项目资料；投标、采购、谈判在工作台内部展示独立操作面板。识别业务意图后先展示能力及所需参数，提交按钮才调用既有业务接口；合同预审进入受控任务并在需要时转人工审核，不显示虚假的任务成功。

投标、采购、谈判不再作为独立侧边栏菜单出现；旧链接重定向到工作台对应面板。结果必须保留来源、版本、页码、任务状态和审批入口。工作台面板切换保留进行中的操作，切换租户或项目时隔离并重新读取所属上下文。

### 4.3 页面模板

每个页面必须包含：页面标题、面包屑/项目上下文、主操作、筛选/搜索区、内容区、状态反馈、空状态和错误恢复操作。

## 5. 通用组件规格

### 5.1 状态标签

统一显示：处理中、待审批、已恢复、成功、失败、已取消、已归档、证据不足、降级。标签同时包含文字和颜色。

### 5.2 任务卡

显示任务 ID、工作流、项目、当前阶段、状态、创建时间、进度/步骤、下一步操作、错误摘要和产物数量。点击进入详情，不把长 JSON 直接铺在列表中。

### 5.3 证据卡

显示来源名称、版本、页码/实体定位、片段摘要、分数、置信度和“打开原文/定位”按钮。无证据时显示“系统拒绝猜测”，不能显示空白。

问答识别到业务意图时，先显示意图名称、将调用的能力、输入文件/项目范围、是否需要审核和缺失参数。用户确认后才创建合同审核、正式标书审查或采购任务；规范查询和普通标书定位可直接返回。

### 5.4 审批卡

显示审批类型、风险、将要执行的动作、输入版本、差异摘要、操作者和批准/驳回/补件按钮。危险操作按钮必须二次确认并要求填写原因（可按租户策略设置）。

### 5.5 JSON/日志查看器

- 默认显示用户可读摘要。
- JSON 原文放在可展开折叠面板，支持复制、搜索和格式化。
- 长文本、哈希和日志使用等宽字体，不能阻塞主页面滚动。
- 错误字段高亮，显示 `trace_id` 和可执行的重试建议。

## 6. BIM Agent 页面规格

页面只出现一个“BIM Agent / 图纸到模型交付”任务，不显示 B1～B5 为独立任务。页面按步骤条展示内部阶段：上传配置、图纸识别、门禁审核、Revit Dry-run、模型交付。

必须提供：

- 文件上传：PDF/DWG/DXF，格式族校验、大小提示和删除/替换。
- 配置表单：项目、楼层、比例、坐标原点、墙柱材料、Revit 工作模型策略。
- 识别摘要：墙、柱、异形柱、轴网、连接点、洞口待处理数。
- 几何证据预览：原图、识别轮廓、未识别区域和警告。
- WallModel 审批：构件属性、墙厚、连接、碰撞、证据和 JSON 展开。
- Dry-run 审批：目标工作副本、Level、族/类型、预计新增/修改/回滚风险。
- 交付结果：RVT、实际视图、独立叠图、Model Diff、审计报告和参数写入统计。
- 叠图指标：edge IoU、源覆盖率、Revit 精确率、相似度和阈值；未达标显著显示失败。

## 7. 表单、表格和反馈

- 表单标签在输入框上方；必填项使用文字“必填”，不只用红色星号。
- 输入错误在字段旁显示原因、示例和修复方式。
- 提交按钮显示动作动词，如“启动 BIM Agent”“批准并执行 Dry-run”“批准 Revit 写入”。
- 长任务不使用无限转圈，显示阶段、已完成步骤、最近事件和预计等待原因。
- 表格支持分页、排序、列显隐和导出；默认按最新任务/风险优先。
- 成功 Toast 只用于短确认，关键结果必须留在页面卡片和任务时间线。

## 8. 无障碍与可用性

- 键盘可完成登录、筛选、审批和下载。
- 交互元素有可读 aria-label；焦点顺序与视觉顺序一致。
- 文本与背景对比度符合 WCAG AA；颜色状态有文字补充。
- 错误使用 `role=alert`；SSE 更新不能抢走用户焦点。
- 关键按钮不依赖 hover 才可见。

## 9. 响应式与性能

- 首屏先加载项目上下文和骨架屏，再加载大型表格/叠图。
- 任务事件按游标增量更新，避免每次刷新全量拉取。
- 大文件上传显示进度、暂停/重试和最终哈希校验。
- 叠图和 JSON 使用懒加载；不在列表页加载完整 RVT 或大图。
- 组件过渡使用 150～250ms 的 opacity/transform，禁止阻塞式全屏 loading；上传和长任务必须保留可操作的取消、重试和错误详情。
- 遵循 `prefers-reduced-motion`；减少动态效果设置下禁用页面位移、装饰动画和悬浮位移。面板切换不能为了动画卸载正在运行的任务组件。
- 工作台的业务面板与全局问答区域需明确分组，避免多个“发送”按钮含义不清；业务输入不自动拼入 QA 上下文。

## 10. 统一错误文案

错误必须包含：发生阶段、用户能做什么、是否可重试、Trace ID。示例：

> Revit 工作模型中没有找到楼层“B1”，因此未执行写入。请在项目楼层映射中选择真实 Revit Level 后重试。Trace：`trace_xxx`。

禁止使用“系统异常”“请求失败”作为唯一提示，也禁止展示 Python 堆栈。

## 11. UI 验收清单

- [ ] 每个页面都有租户/项目上下文。
- [ ] 角色看不到无权菜单，直接访问仍由后端拒绝。
- [ ] 任务刷新、断线和重连不丢状态。
- [ ] 审批页面同时提供可读摘要和 JSON/证据展开。
- [ ] BIM 页面只展示一个 BIM Agent 任务。
- [ ] 叠图明确来自原图和实际 Revit 视图的独立渲染。
- [ ] 失败有阶段、原因、可重试性和 Trace ID。
- [ ] 前端 lint、typecheck、build 和关键流程手工验收通过。
